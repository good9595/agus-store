# AgusStore

> Plataforma e-commerce full-stack desarrollada con Next.js, Prisma y PostgreSQL.

## Overview

Una solución moderna de comercio electrónico construida en Next.js, que incluye autenticación de usuarios, catálogo de productos organizado por categorías, gestión de carrito y persistencia de datos mediante Prisma ORM.

## Features

- Autenticación segura (Next-Auth + bcrypt).
- Catálogo dinámico con gestión de categorías.
- Sistema de rutas API para operaciones CRUD de productos y categorías.
- Interfaz responsiva diseñada con React Bootstrap y componentes optimizados.

## Stack

Next.js 13 · TypeScript · Prisma ORM · PostgreSQL · Next-Auth · React Bootstrap · bcrypt.
